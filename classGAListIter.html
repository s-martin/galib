Detailed Description

template<class T>
class GAListIter< T >

Iterator for GAList.

An iterator is independent of the iterator embedded in the list and of other iterators. Navigation is circular: next() at the tail wraps to the head and prev() at the head wraps to the tail. The iterator is invalid (current() returns nullptr) until it is moved onto an element, and when the list is empty.

When we create a new list iterator from another iterator, it defaults to the same node. If it is created with a list as its argument, it defaults to the list's iterator's current position.
