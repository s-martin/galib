Detailed Description

template<class T>
class GAList< T >

List of objects, implemented on top of std::list.

You never get nodes back, you get pointers to the contents of the nodes. We include an iterator in this object so that you can navigate through the list. You can create another iterator (GAListIter) and assign it to your list so you can have multiple iterators. All of the actions take place relative to the current location of the embedded iterator. Be careful so that you don't end up with an iterator dangling at an element that no longer exists.

The list behaves as a circular list: next() at the tail wraps to the head and prev() at the head wraps to the tail.

The contents must be copy constructible.
